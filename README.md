# CSTIASA
# Customer Support Ticket Intelligence & Automated Service Assistant

## Project Overview
This project aims to develop an intelligent customer support system that uses Machine Learning and Natural Language Processing to classify customer support tickets and assist in handling customer queries efficiently.

## Objectives
- Analyze customer support tickets.
- Classify tickets based on ticket type.
- Understand ticket priority and status.
- Explore patterns in customer complaints.
- Plan AI-assisted summaries and response suggestions.
